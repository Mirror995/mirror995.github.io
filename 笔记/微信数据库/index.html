准备工作#

获取到auth_info_key_prefs.xml和EnMicroMsg.db。由于操作简单，笔者不赘述。

具体操作#

首先打开auth_info_key_prefs.xml，记录_auth_uin字段的值。
然后计算数据库密码，公式为：

$$\text{key} = \text{substr}(\text{MD5}(1234567890ABCDEF[\_auth\_uin]),0,7)$$

很多人说拼在_auth_uin前面的是IMEI。不过注意到高版本微信为了符合安卓规范，并不申请“电话”权限，因此该部分实为硬编码的初始值。

然后无脑复制粘贴下面的命令：

brew install sqlcipher
sqlcipher EnMicroMsg.db

PRAGMA key = '[KEY HERE]';
PRAGMA cipher_use_hmac = off;
PRAGMA kdf_iter = 4000;
PRAGMA cipher_page_size = 1024;
PRAGMA cipher_hmac_algorithm = HMAC_SHA1;
PRAGMA cipher_kdf_algorithm = PBKDF2_HMAC_SHA1;
ATTACH DATABASE 'plaintext.db' AS plaintext KEY '';
SELECT sqlcipher_export('plaintext');
DETACH DATABASE plaintext;
